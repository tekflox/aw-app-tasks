# Scheduled Tasks

Scheduled Tasks lets an AW Workspace run prompts and checks on a schedule. It is built for recurring reminders, automated agent prompts, lightweight command checks, and notifications when something needs attention.

## What It Does

- Creates and manages scheduled tasks from the workspace UI.
- Runs tasks on cron-like schedules.
- Supports prompts sent into reusable terminal or agent sessions.
- Supports lightweight shell checks that notify when a notable result occurs.
- Keeps task history and state in the workspace.

## Why Use It

Use this app when work should happen later, repeat regularly, or notify the user only when a condition changes. It is useful for periodic status checks, recurring maintenance prompts, monitoring commands, follow-up reminders, and scheduled agent work.

## How To Use It

Install the app and open Scheduled Tasks from the workspace navigation. Create a task, choose the schedule, select the run type, and save it. The workspace scheduler will run due tasks automatically.

## What It Delivers

The app gives AW Workspace a reliable scheduling layer. Users can automate recurring prompts and checks without keeping a separate terminal open or manually remembering each follow-up.
